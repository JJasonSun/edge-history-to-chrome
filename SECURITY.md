# Security

## Private data

A prepared profile contains browsing URLs, page titles, and timestamps. Keep the source CSV and generated SQLite files off GitHub.

Do not attach browser exports, profile databases, screenshots with URLs, passwords, cookies, or autofill values to an issue. Reproduce a bug with `example.com` data.

## Reporting a vulnerability

Use [GitHub's private vulnerability report](https://github.com/JJasonSun/edge-history-to-chrome/security/advisories/new). Describe the affected command and version. Remove browser data, usernames, and local paths from logs before sending them.

Public issues are suitable for feature requests and bugs that use synthetic data.

## Supported versions

The project is in its initial release. Security fixes target the latest version on the `main` branch.
